## Findings considered and rejected (do not re-audit)

- **PBKDF2 at 10 000 iterations** (`src/core/encryption/internals.ts:102-105`):
  protocol-constrained — must match Actual server/desktop derivation for the
  same password+salt. Raising it unilaterally breaks decryption interop.
  Tracked as "adopt versioned KDF params if upstream adds them". Plan 011's
  determinism test pins the current params on purpose.
- **ATS / `NSAllowsLocalNetworking`**: correctly configured
  (`NSAllowsArbitraryLoads=false`); local-network plaintext is a deliberate
  self-hosting affordance. Watch item only: `app.config.ts` doesn't declare
  the ATS block the committed dev plist has — verify prod builds carry the
  same policy on the next release.
- **LIMIT/OFFSET string interpolation**
  (`src/core/domain/transactions/index.ts:54-58`, `query.ts:239`,
  `src/core/queries/compiler.ts:508-509`): values are internally-supplied
  typed numbers today; defense-in-depth only. Fold a `Number()` coercion into
  any future touch of those files rather than a dedicated change.
- **features/ + design-system/ coexistence and the 31 fat routes**: by-design
  strangler state, already the documented migration backlog
  (ARCHITECTURE.md §mapa de migración); plans 007/008/010 chip at it where
  the replacement already exists.
- **core→stores prefsStore imports** (5 files, check-arch WARN): documented
  port compromise.
- **Sentry breadcrumb context spread**
  (`src/ui/feedback/ErrorChannelConsumer.tsx:16-28`): currently benign
  (operation names/status codes only, verified); revisit only if richer error
  context is ever attached.

## Deferred — investigate before planning (confidence too low for a fix plan)

- **Concurrent top-level mutations share the module-global batch buffer**
  (`src/core/sync/batch.ts:19-20`): if two async flows interleave across an
  await (e.g. user save vs post-sync `advanceSchedules`), the inner flow's
  messages land in the outer flow's undo group. Mechanism certain, frequency
  unknown. Investigate: add a dev-mode assertion counting overlapping
  top-level batches before designing a mutator queue (upstream uses
  `runMutator` serialization).
- **Split children with a transfer payee may spawn mirror transactions**
  (`src/core/domain/transactions/index.ts:103-110` + `save.ts:127-171`
  unconditionally run the transfer `onInsert` hook per child; upstream
  suppresses it for children). Unverified whether the UI can reach this
  state — check whether a split's payee can be a transfer payee before
  fixing.
- **Table-granularity liveQuery invalidation** (`liveQuery.ts:50-56`): every
  write to `transactions` re-runs all live queries on it. Real cost unknown
  on-device; measure before designing row-aware invalidation.
