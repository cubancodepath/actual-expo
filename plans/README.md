## Findings considered and rejected (do not re-audit)

- **`dollarsToCents`/`centsToDollars` strip the sign via `Math.abs`**
  (`src/lib/currency.ts:24-37`): by-design magnitude contract. All callers
  (only `src/hooks/useExpressionMode.ts`) guard `result >= 0` before converting,
  and sign is applied separately via `signedCents(magnitude, inflow)`. Not a bug.
- **`heroui-native-pro` pinned to `1.0.0-beta.5`** (`package.json:75`): real
  maintenance risk but no action available until a stable release exists.
  **Watch item**: when 1.0.0 stable lands, bump to caret with a UI smoke pass
  over the Pro components in use (date pickers, steppers).
- **Fat-route extraction as a one-shot project** (24 routes >120 lines): the
  strangler migration already handles this "when touched" (ARCHITECTURE.md);
  plan 019 adds a ratchet so the count can only shrink. Extracting all 24 in
  one push was judged not worth the regression risk.
- **PBKDF2 iteration count** (`src/core/encryption/`): protocol-constrained —
  must match Actual server/desktop derivation for interop. Do not raise
  unilaterally.
- **Sentry DSN in source** (`app/_layout.tsx:58`): Sentry DSNs are
  public-by-design identifiers, not secrets.
- **`.env.local` presence**: untracked and gitignored (verified) — not a
  committed-secret finding; plan 022 adds the missing template only.
- **core→stores/services imports** (check-arch WARN): documented port
  compromise (docs/architecture-differences.md).
- **Row-level (filter-aware) liveQuery invalidation**: real on-device cost of
  table-level invalidation unknown; plan 011's coalescing is the cheap 80%.
  Measure before designing row-aware matching.
- **pnpm audit**: no known vulnerabilities on prod deps at `cab6621` — nothing
  to fix.
